# Project Shield Futures

> **Protecting Minds, Building Futures – A Gun-Free Tomorrow**

A modern, elegant, and minimalist awareness website against gun violence, designed for classroom presentation.

## 📁 Project Structure

```
Final-Task/
├── index.html          # Main website file (single HTML+CSS file)
└── README.md           # This documentation file
```

## 🚀 How to Use

1. **Open the website**: Simply open `index.html` in any modern web browser
2. **No server required**: Works as a static file - just double-click to open
3. **For presentation**: Use scroll wheel, arrow keys, or mouse to navigate through sections

## 🎯 Website Structure (5 Sections)

### Section 1: HERO & PRESENTATION
- Main Title: "PROJECT SHIELD FUTURES"
- Slogan: "Protecting Minds, Building Futures – A Gun-Free Tomorrow"
- Location Theme: Schools • High Schools • Universities
- Large shield icon

### Section 2: PROJECT 1 – STRICT BACKGROUND CHECKS & AGE CONTROL
- Number: 1
- Title: "STRICT BACKGROUND CHECKS & AGE CONTROL"
- 3 Bento Cards:
  - Comprehensive Checks (Criminal History, Mental Health, Domestic Violence)
  - Age Verification (Minimum Age 21, ID Required, Strict Enforcement)
  - National Database (Centralized Records, Real-time Updates, All States)

### Section 3: PROJECT 2 – CAMPUS ENTRY CONTROL & SAFETY
- Number: 2
- Title: "CAMPUS ENTRY CONTROL & SAFETY"
- 3 Bento Cards:
  - Access Badges (Students, Staff, Authorized Personnel)
  - Entry Points (Metal Detectors, Bag Checks, Single Entry)
  - Security Personnel (Professional Agents, Trained Staff, Dedicated Teams)

### Section 4: PROJECT 3 – 24/7 PSYCHOLOGICAL SUPPORT
- Number: 3
- Title: "24/7 PSYCHOLOGICAL SUPPORT"
- 3 Bento Cards:
  - Helpline (24/7 Available, Confidential, Free)
  - Professionals (Psychologists, Counselors, Trained Specialists)
  - Support For (Students, Parents, Teachers)

### Section 5: HOW WE ACT (CAMPAIGN & DEPLOYMENT)
- Title: "OUR ACTION PLAN: HOW WE DEPLOY"
- 3 Deployment Cards:
  - Social Media (Short Impactful Videos, 15-25 Years Old, TikTok Instagram)
  - Campus Posters (Schools, High Schools, Universities, QR Codes)
  - National Implementation (All Schools, All States, Policy Advocacy)

### Footer
- Logo: SHIELD FUTURES
- Message: Peace • Education • Safety • Hope

## 🎨 Design Features

### Color Palette
- **Deep Black**: #0F172A (Background)
- **Off-White**: #F8FAFC (Card backgrounds)
- **Emerald Green**: #10B981 (Primary color - Hope)
- **Safety Orange**: #F97316 (Accent color)

### Typography
- **Font**: Inter (Google Fonts)
- **Weights**: 300, 400, 500, 600, 700, 800, 900
- **Style**: Modern, clean, highly readable

### Layout Style
- **Bento Grid**: Clean card-based layout
- **Responsive**: Adapts to mobile, tablet, and desktop
- **Animations**: Smooth scroll, fade-in effects
- **Icons**: Emoji-based for universal compatibility
